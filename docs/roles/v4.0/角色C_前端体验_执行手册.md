## 四、技术速查（可直接复制）

### 4.1 初始化命令

npm create vite@latest frontend -- --template vue
cd frontend && npm i pinia vue-router element-plus echarts katex
npm run dev

### 4.2 路由与页面

| 路由 | 页面 | 要点 |
|---|---|---|
| /login | 登录 + 学科选择 | 学生/家长双入口 |
| /home | 学习主页 | 主题项目 + 进度卡片 |
| /study | 学习主界面 | AI 对话 + 题目 + 路径 |
| /mistakes | 错题本 | 错因标签 + 重新作答 |
| /parent | 家长端 | 学情报告 + 错题统计 |

### 4.3 组件清单

| 组件 | 说明 |
|---|---|
| DiagnoseCard | 单选/填空/应用题三种题型 |
| ChatPanel | AI 同伴：打字机效果 + katex 公式 + 表情 |
| MistakeList | 错题列表 + 错因标签 + 重做入口 |
| ProgressRadar | echarts 雷达图 + 知识图谱缩略图 |
| BadgeWall | 经验值 / 徽章 / 连续打卡 |
| ParentReport | 家长端学情报告 |

### 4.4 儿童友好设计要点

| 项 | 要求 |
|---|---|
| 字号 | 正文 ≥16px，按钮 ≥18px |
| 操作 | 点击目标 ≥44px；尽量少让小学生打字（选择题/语音优先） |
| 视觉 | 圆角卡片、明亮配色、答对/答错有动画反馈 |
| AI 同伴 | 卡通角色贯穿全 App，情绪随学习状态变化 |

## 五、我的时间与风险

| 风险 | 我的动作 |
|---|---|
| UI 不够儿童友好 | Day5 草图先请 2 位同学评审；参考 Khan Academy 风格 |
| 依赖 API 未就绪 | 周 1~2 用 A 的 mock 数据开发，不等后端 |
| 页面太多做不完 | 家长端放最后；先保学习主界面 |
