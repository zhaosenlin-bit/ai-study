# v4.0 角色设计手册（我的方案）

本目录是《我的方案 v4.0》中 4 个角色的执行手册，与课堂分组角色（A-E）不同：
- 课堂分组角色在 `../00-role-assignment-board.md` 等文件，按 5 人（A-E）划分。
- 本目录按 **v4.0 4 人制** 划分，更细粒度、配套《我的方案 v4.0》使用。

## 四个角色

| 角色 | 方向 | 对应分支 | 核心职责 |
|------|------|----------|----------|
| 角色 A | 架构 / 后端 | `feature/agent-core` | 四大 Service、Agent 编排、FastAPI、Docker |
| 角色 B | 大模型 / 知识库 | `feature/llm-all` | Prompt 工程、知识图谱、题库、错因分析 |
| 角色 C | 前端 / 体验 | `feature/frontend-ui` | React、UI、AI 精灵体验、家长端 |
| 角色 D | 产品 / 数据 / 演示 | `feature/data-demo` | 演示脚本、数据看板、商业叙事 |

## 文件清单

- `角色A_架构后端_执行手册.md` / `.docx`
- `角色B_知识库大模型_执行手册.md` / `.docx`
- `角色C_前端体验_执行手册.md` / `.docx`
- `角色D_产品数据演示_执行手册.md` / `.docx`

每份手册包含：角色卡、每周动作卡、与其他角色的对接清单、风险与验收。
