## 四、技术模板（可直接复制）

### 4.1 知识图谱节点 JSON 示例

{"id":"kp_fraction_addition","name":"分数加减法","grade":5,"subject":"math","difficulty":3,"prerequisites":["kp_fraction_concept","kp_common_multiple"],"description":"同分母/异分母分数加减运算"}

### 4.2 跨学科主题项目模板（如“太空探险”）

| 学科 | 子任务示例 | 绑定知识点 |
|---|---|---|
| 数学 | 估算火箭燃料 / 轨道数据统计 | 数据统计、应用题建模 |
| 语文 | 写一篇《太空探险日记》 | 写作、口语表达 |
| 英语 | 太空主题词汇 + 简单对话 | 基础词汇、日常对话 |
| 综合 | 作品存档（文字/图片/音频） | 项目进度跟踪 |

### 4.3 RAG 检索链路

| 步骤 | 说明 |
|---|---|
| 1 建索引 | 样例题 → embedding → 存入 Chroma collection（按年级/学科切分） |
| 2 检索 | query 取 top-k=3 → 返回知识点 id + 相似题 |
| 3 校验 | 检索结果必须能映射到知识图谱节点，否则降级为关键词匹配 |

### 4.4 Prompt 模板骨架（4 套）

| 模板 | 核心指令 |
|---|---|
| 诊断 | 你是小学 X 年级 Y 科老师，根据答案判断错因（粗心/概念缺失/计算错误），输出 JSON {error_type, kp_id} |
| 讲解 | 用小学生能懂的语言分 3 步讲解，不直接给答案 |
| 引导 | Socratic 提问：一次只给一个提示，等学生回答再继续 |
| 反思 | 回顾最近 5 轮对话，判断是否需要调整路径，输出建议 |

### 4.5 LLM 切换封装

| 项 | 要点 |
|---|---|
| 统一接口 | llm.chat(messages, model="spark\|deepseek\|qwen") |
| 配置 | 环境变量 LLM_PROVIDER；星火主 + DeepSeek 备 |
| 容错 | 超时/限流自动切备用模型；本地开发用 mock |
