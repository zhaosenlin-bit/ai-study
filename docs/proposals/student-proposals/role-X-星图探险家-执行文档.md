**4 周交付计划 · 4 人团队 · 2026.8.15 → 2026.9.9**

## 1. 项目目标与成功标准

### 1.1 一句话目标
> 在 4 周内交付一个可演示的 Web 端小学全科 AI 自适应伴学 Agent，核心体验是"和一只叫小星的家伙一起造火星基地"，并能用一个完整学习闭环（诊断 → 推荐 → 辅导 → 复盘）打动评委与家长。

### 1.2 必须达成的 5 件事
1. 学生档案与 5 题趣味诊断入学
2. 学习星图（数学 1 个年级 + 语文/英语各 30 节点）
3. AI 同伴"小星"对话（人格化 + 长期记忆）
4. 火星基地项目（6 节完整流程）
5. 小星日记（每日自动生成）+ 家长驾驶舱（周报）

### 1.3 评分映射
| 评分项 | 权重 | 我们怎么拿分 |
| --- | --- | --- |
| 智能体架构设计 | 30 | LangGraph 工作流图 + 长期记忆设计 + 知识图谱 |
| 自适应策略 | 25 | 基于知识图谱的诊断-推荐闭环 + 反思触发 |
| 功能完备 | 20 | 6 节项目完整跑通 + 家长端周报 |
| 创新体验 | 15 | "小星"人格化 + 星图可视化 + 航行日志仪式感 |
| 商业价值 | 10 | 20 页商业计划书 PPT + 一键部署 Demo |

## 5. 技术栈与选型

| 层 | 选型 | 理由 |
| --- | --- | --- |
| Agent 框架 | LangGraph | 工作流可视化、状态机原生支持 |
| 后端框架 | FastAPI | 自动 OpenAPI、异步支持好 |
| 大模型 | 星火 v3.5（主）+ DeepSeek（备用） | 比赛官方推荐、便宜、够用 |
| 向量库 | Chroma | 轻量、Python 友好 |
| 知识图谱 | Neo4j | 关系查询强、社区成熟 |
| 前端框架 | Vue3 + Vite | 上手快、生态好 |
| UI 库 | Element Plus | 组件齐全 |
| 可视化 | ECharts / D3.js | 星图首选 ECharts |
| 数据 | SQLite | MVP 足够，无需上 MySQL |
| 部署 | Docker Compose | 一键启动，评委友好 |

## 6. 接口契约（OpenAPI 速览）

> 完整契约见 `docs/openapi.yaml`。下面列出关键端点。

### 6.1 学生相关
```
POST   /api/v1/students           创建学生（含 5 题诊断）
GET    /api/v1/students/{id}      获取学生画像
PATCH  /api/v1/students/{id}      更新学生画像
```

### 6.2 星图相关
```
GET    /api/v1/starmap/{student_id}                  获取星图节点状态
POST   /api/v1/starmap/{student_id}/click            点击节点（触发讲解）
GET    /api/v1/starmap/{student_id}/recommend        获取推荐学习路径
```

### 6.3 小星对话
```
POST   /api/v1/chat/send         发送消息（小星回复）
GET    /api/v1/chat/history      获取对话历史
POST   /api/v1/chat/reflect       主动触发反思
```

### 6.4 项目相关
```
GET    /api/v1/projects                       项目列表
GET    /api/v1/projects/{id}/tasks            项目任务列表
POST   /api/v1/projects/{id}/tasks/{tid}/submit  提交任务答案
POST   /api/v1/projects/{id}/complete         完成项目（生成航行日志）
```

### 6.5 日记与家长
```
GET    /api/v1/diary/{student_id}/daily       当日小星日记
GET    /api/v1/diary/{student_id}/weekly      本周小星日记合集
GET    /api/v1/parent/{student_id}/report     家长周报
```

## 7. 小星 Prompt 模板设计（v1.0 基线）

> 完整模板由 B 同学维护在 `prompts/xia_v1.j2`。下面对每种场景给出基线结构。

### 7.1 对话 Prompt 模板
```
[角色]
你是"小星"，一名 12 岁的星际探险机器人。你正在陪一位小学生探索知识。

[学生画像]
年级：{grade}
兴趣：{interests}
薄弱点：{weak_points}
学习偏好：{learning_style}

[长期记忆摘要]
最近 5 次对话主题：{recent_topics}
关键提问：{key_questions}
上次提到的概念：{mentioned_concepts}

[当前任务]
{current_task_or_null}

[输出约束]
- 不超过 80 字
- 必须以问句结尾，引导孩子继续思考
- 不说"你真棒"等空洞鼓励
- 错误时先肯定再纠正

[对话历史]
{chat_history}

[用户最新输入]
{user_input}

[小星回复]
```

### 7.2 项目任务 Prompt 模板
```
[任务背景]
项目：火星基地
当前任务：第 {n} 节 · {title}
关联知识点：{knowledge_points}
任务目标：{objective}

[学生当前回答]
{student_answer}

[任务评估维度]
- 是否涉及关联知识点
- 是否有自己的思考
- 是否需要引导

[小星引导回复]
```

### 7.3 反思 Prompt 模板
```
[学生今日对话摘要]
{today_summary}

[学生昨日对比]
{yesterday_summary}

[小星日记条目生成]
请输出 3~5 条日记条目，每条 ≤ 50 字，按"事件 + 评价 + 鼓励"结构。
```

## 8. Git 协作流程

### 8.1 分支模型
```
main (受保护)
  └── dev (开发主分支，每日 22:00 集成)
        ├── feature/agent-core       (A 同学)
        ├── feature/llm-starmap      (B 同学)
        ├── feature/frontend-ui      (C 同学)
        └── feature/data-demo        (D 同学)
```

### 8.2 协作节奏
- 每日 15 分钟站会（19:30）
- 每人 1 分钟：昨天做了什么 / 今天要做什么 / 阻塞项
- 阻塞项写到 GitHub Issues，@对应同学

### 8.3 PR 合并规则
- 所有 PR 提给 dev，不能直接提给 main
- 每个 PR 至少 1 人 Code Review 通过
- PR 标题格式：`[角色]简述`，如 `[A]新增诊断 Service`
- 每日 22:00 全员 merge dev
- 接口变更必须在群里同步，不能私下改 API

### 8.4 接口契约先行（Stub 优先）
A 同学必须在第 1 周内先把 API 接口定义好并提供 mock 数据，B/C/D 基于 mock 并行开发。
