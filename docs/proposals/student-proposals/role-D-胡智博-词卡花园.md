## 2. 用一句大白话说明创意

把"错词本"从一张红色错误列表，变成一个看得见成长的花园：每个错词是一粒种子，按复习计划"浇水"（复习），连续答对就让种子发芽、长叶、开花，最终开出"记住啦"的花。

```text
答错 → 种子入土 → 第 1 次复习对 → 发芽 → 第 2 次复习对 → 长叶
→ 第 3 次复习对 → 开花 → 花牌：banana，我记住了！
```

## 3. 解决什么真实问题

学生怕复习、觉得错词本是"批评清单"；家长看不到孩子复习有没有用；评委在路演里只看得到静态数据，看不到"自适应复习调度"在起作用。

花园让复习变成有即时正反馈的成长过程，也把 SM-2 复习调度"画"了出来，评委一眼看懂自适应策略。
