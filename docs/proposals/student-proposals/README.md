## 一句话定位

在 ai-study v0.3 五人制基础上，提出一个**跨学科主题项目 + AI 同伴人格化**的差异化升级方案——代号「星图探险家」。不替换现有三科并列闭环，而是在现有 demo 上叠加一条「项目式学习」路径，作为 v1.0 路演的"加分项"。

## 与 PRD v0.3 的关系

| 维度 | PRD v0.3 现状 | 星图探险家方案 |
| --- | --- | --- |
| 学习入口 | 今日任务（每日 3 个） | 保留 + 增加"项目入口" |
| 跨学科 | 未强调 | **强化**：一个火星基地项目串起语数英 6 节任务 |
| 长期记忆 | emotion_state、mastery map | **产品化**：小星日记（每日生成）+ 航行日志（项目结束） |
| AI 伙伴 | 紫色发光星星 | **人格化**：命名为"小星"，4 情绪 + 口头禅 + 记忆引用 |
| 知识图谱 | 隐藏在后台 | **可视化**：学习星图（数学=北天星座 / 语文=南天 / 英语=赤道） |
| 仪式感 | 错题本复习 | **新增**：每个项目结束生成航行日志 |

## 接入建议

### 优先级
- **P0**：采纳"小星"人设 + AI 伙伴 4 情绪（E 一人 2 天可完成）
- **P1**：采纳"小星日记"作为长期记忆的可视化（E + A 协作 3 天）
- **P1**：采纳"学习星图"作为知识图谱的可视化（E + A 协作 3 天）
- **P2**：火星基地项目（v1.0 路演如果时间够，作为加分演示；v1.1 完整做）

### 与现有分工的兼容

| 角色 | 星图探险家为其加的工作 |
| --- | --- |
| A（Agent 后端） | + 长期记忆 Service（读写 + Chroma 向量检索） |
| B（数学） | + 火星基地第 2/3 节任务的数学知识点 |
| C（语文） | + 火星基地第 1/4 节任务的语文知识点 |
| D（英语） | + 火星基地第 5 节任务的英语知识点 |
| E（前端） | + 小星人设组件 + 星图组件 + 日记组件 |

### 不冲突的边界
- 不替换现有 7 个页面，只在原有 UI 上叠加新模块
- 不改 OpenAPI 契约（所有新增端点向后兼容）
- 不改 e2e 测试（原有 demo.spec.ts 保持不动）

## 期望收益
