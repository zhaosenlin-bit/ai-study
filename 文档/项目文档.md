> 2026 iFLYTEK AI 开发者大赛「自适应学习路径决策与伴学」
> 文档版本：v1.0（2026-08-28）

---

## 一、项目概述

**AI 伴学 · 让学习更有趣** —— 面向 3-6 年级学生的自适应学习平台，覆盖语文、数学、英语三科。

核心思路：**AI 智能体通过「每日诊断 + 长期记忆」持续认知每个学生**，每次交互都沉淀到知识库，让建议、计划、题目越来越贴合个人需求。

```
认知（画像/谈心） → 测试（每日诊断） → 记忆（知识库） → 再认知（个性化输出）
```

## 二、核心功能

| 功能 | 说明 | 入口 |
|---|---|---|
| 🧪 **每日诊断** | 每天一套六类诊断题（数学口算/应用题、语文写古诗/阅读、英语看中文选英/连词成句），判分 + 弱项识别（<60% 标红）+ 错题自动入本 | 登录首页 /diagnosis/today |
| 🦊 **AI 画像** | 谈心式问卷（学习时长/时段/兴趣/目标/风格/谈心记录），AI 全方位记住用户 | 首次登录自动引导 |
| 🧠 **长期记忆知识库** | 画像、诊断结果、对话、语音、拍照记录全部入库，语义检索快速匹配需求 | POST /api/v1/memory |
| 📸 **AI 智能改卷** | 拍照练习 → 选学科 + 自评对错 → AI 批改反馈 → 入知识库 | /practice（错题本入口） |
| 📒 **错题本 + 每日复习** | 答错自动入本（次日到期），今日待复习/待复习分组 | /mistakes |
| 📚 **教科书区** | 对应年级三科课本封面，点开进学科课程 | 学习进度页顶部 |
| 🎤 **语音交流** | 对话页语音输入（浏览器语音识别转文字） | /chat/:subject |
| 💬 **AI 伴学对话** | 8 节点 LangGraph 工作流，带判题/错题/复习能力 | /chat/:subject |
| 📊 **家长看板/报告** | 家长查看孩子学习进度与报告 | /home /report |
| 📱🖥️ **双端适配** | 手机端底部导航 + 电脑端左右栏 | 响应式 |

## 三、技术架构

```
┌──────────────────────────── 前端（Vite + React 18 + TS） ────────────────────────────┐
│  落地页/登录  今日诊断页  AI画像页  拍照改卷页  课程答题页  错题本页  对话页  家长看板  │
│  左侧题目目录（语数英24课）  右侧功能栏  底部导航（移动端5 Tab）  AI 伙伴组件         │
└────────────────────────────────────┬──────────────────────────────────────────────┘
                                     │ /api（Vite 代理同源）
┌────────────────────────────────────▼──────────────────────────────────────────────┐
│  FastAPI 后端（服务/api）                                                            │
│  认证 / 课程 / 诊断(每日) / 学生画像 / 知识库 / 拍照改卷 / 错题复习 / 对话 / 报告      │
│  ┌──────────┐ ┌──────────┐ ┌────────────┐ ┌───────────────┐                        │
│  │ 结构化数据库 │ │ 本地向量知识库 │ │ 模型网关      │ │ 题目生成器      │             │
│  │ SQLite     │ │ 2-gram向量 │ │ spark/deepseek│ │ 口算/应用/古诗/ │             │
│  │ (事实)     │ │ +余弦检索  │ │ qwen/minimax │ │ 阅读/单词/连词  │             │
│  │            │ │ (认知)     │ │ /mock        │ └───────────────┘                │
│  └──────────┘ └──────────┘ └────────────┘                                          │
└──────────────────────────────────────────────────────────────────────────────────────┘
```

### 模型网关（服务/agent/模型网关.py）
- 环境变量：`MODEL_PROVIDER`（或 `LLM_PROVIDER`）= `mock|spark|deepseek|qwen|minimax`
- `<PROVIDER>_API_KEY` / `<PROVIDER>_BASE_URL` 未配置自动回退 mock，不抛错
- 用于：AI 批改评语、对话、拍照改卷反馈

### 数据存储设计（数据库 = 事实，知识库 = 认知）

| 数据 | 存放 | 检索 |
|---|---|---|
| 用户/年级/课程进度/错题/诊断结果/改卷记录/练习时长 | SQLite（事实） | SQL |
| 画像 Profile（mastery/weakness/goals） | SQLite students/student_profile | 实时读 |
| 对话/谈心/语音/图片描述/弱项等长期记忆 | memories 表 + 2-gram 向量 | 余弦相似度召回 |
| 上传练习图片 | 本地文件 /data/practice/ | 静态服务 |

> 知识库采用字符 2-gram 哈希向量 + 余弦相似度（零依赖、中文友好）；
> 后续接入 minimax embedding / 云向量库时只需替换向量函数，接口不变。

## 四、快速开始

### 依赖
- 后端：Python 3.12+，`pip install -r 服务/api/requirements.txt`
- 前端：Node 18+，`npm install`（应用/web）

### 启动
```bash
# 后端（端口 8000）
cd 服务/api
.venv/Scripts/python -m uvicorn app.主程序:app --port 8000 --host 127.0.0.1

# 前端（端口 5174，/api 自动代理到 8000）
cd 应用/web
VITE_USE_MOCK=false npm run dev
```

**统一访问地址：http://localhost:5174**（页面与接口同源，无需访问 8000）

### 首次使用流程
1. 打开 http://localhost:5174 → 注册/登录（学生或家长）
2. 学生首次登录 → AI 伙伴谈心式画像问卷（6 问）→ AI 记住
3. 进入**今日诊断**（六类题 9 道）→ 提交 → AI 批改 → 六维成绩 + 弱项
4. 答错的题自动进错题本（次日复习）
5. 平时可用：课程做题、AI 对话（可语音）、拍照改卷、教科书区
