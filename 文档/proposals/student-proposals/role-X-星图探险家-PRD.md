# PRD · 星图探险家（StarMap Explorer）

**小学全科 AI 学习伙伴 Agent v2.0 · 跨学科主题式学习**

| 字段 | 值 |
| --- | --- |
| 产品名称 | 星图探险家（StarMap Explorer） |
| 版本 | PRD v2.0（基于 团队协作方案 v1.0 基线升级） |
| 目标用户 | 小学 3~6 年级学生 + 家长（轻度参与） + 老师（可选） |
| 核心场景 | 课后 30 分钟自主学习 / 周末项目式探究 / 假期专题训练 |
| 差异化卖点 | 学习星图 · AI 同伴"小星"人格化 · 长期记忆"小星日记" · 主题项目舰队 |
| 技术基线 | LangGraph Agent + 星火大模型 + Chroma + Neo4j + Vue3 |
| 交付形态 | Web 端（PWA 友好）+ 演示视频 + 商业计划书 |

---

## 1. 产品愿景

让每个小学生都能在 AI 的陪伴下，完成一次"像样的"跨学科探究项目，并在这个过程中悄悄把语数英都练了一遍。

我们不与"刷题 App"竞争速度，也不与"AI 答疑"竞争响应。我们竞争的是孩子的回忆：当一个孩子 10 年后回忆起小学，他会不会提到"我曾经和一只叫小星的家伙，一起造过火星基地"？

---

## 2. 目标用户画像

### 2.1 主用户：小学三~六年级学生
- 年龄：8~12 岁
- 典型场景：放学回家 19:00~20:30，家长在客厅工作，孩子在房间写作业或"自己研究点东西"
- 真实痛点：
  - 题目做错了没人讲，爸妈讲两遍就烦
  - 作文写不出来，对着空白格子发呆
  - 英语单词背了就忘，没有语境
  - 想"研究点厉害的"（宇宙、恐龙、AI），但家长答不上来
- 隐性需求：被看见、被记住、被认真对待

### 2.2 次用户：家长
- 不参与学习过程，但关心：今天有没有学、薄弱点是什么、要不要报班
- 希望：每周收到一份"孩子这周做了什么"的简报

### 2.3 边缘用户：老师
- 用于课堂拓展或课后作业布置（v2.1 规划）

## 3. 核心价值主张

| 维度 | 价值主张 | 体验表现 |
| --- | --- | --- |
| 跨学科 | 一个项目串起语数英 | "火星基地"项目同时练说明文 / 面积计算 / 英文术语 |
| 长期记忆 | AI 记得孩子说过的每一句话 | "小星日记"自动整理本周孩子的提问与进步 |
| 人格化 | AI 是一个会成长的同伴，不是工具 | "小星"有情绪、有口头禅、有等级，会因为被冷落而"叹气" |
| 可视化 | 学习进度像游戏地图一样可见 | "学习星图"：知识点是星球，掌握度是亮度 |
| 仪式感 | 每个项目结束都有"航行日志" | 项目结束生成图文航行日志，可分享给家长 |

## 4. 产品功能架构

### 4.1 五大模块全景

1. 探险家档案（学生画像）
2. 学习星图（知识图谱可视化）
3. AI 同伴·小星（人格化对话 Agent）
4. 主题项目舰队（火星基地 / 月球车 / 深潜器）
5. 小星日记（长期记忆 + 复盘）
6. 家长驾驶舱（学情周报）

### 4.2 模块详细说明

#### 1. 探险家档案
- 字段：年级 / 兴趣标签 / 薄弱知识点 / 学习偏好（视觉型 / 听觉型 / 操作型）
- 入学方式：5 题趣味诊断（不是试卷，是"你更想造火箭还是潜艇"这种二选一）
- 作用：作为 Agent 中台所有推荐的输入

#### 2. 学习星图
- 形态：夜空中的星座
  - 数学 = 北天星座（基础、规律）
  - 语文 = 南天星座（表达、故事）
  - 英语 = 赤道星座（沟通、连接）
- 节点：每个知识点是一颗"星球"
  - 未点亮 = 灰星
  - 已掌握 = 亮星
  - 反复错 = 红星（需要小星陪伴复习）
- 交互：点击星球 -> 小星讲解 -> 出 1~2 道题 -> 升级或标记为红星

#### 3. AI 同伴 · 小星
- 人设：12 岁左右的星际探险机器人，圆脑袋，会发光
- 语气：不教训、不催促，喜欢用"哎""嗯哼""哦对了"这类口语词
- 情绪系统：
  - 开心（连续答对）
  - 好奇（用户问"为什么"）
  - 担心（用户卡住 30 秒）
  - 傲娇（被冷落 24 小时后再次上线时）
- 记忆引用：会主动调用历史，"你两周前问过类似的问题呢，当时你是这么想的……"

#### 4. 主题项目舰队（v1.0 优先做"火星基地"）
- 火星基地（旗舰）：6 节项目课，串起以下知识点：
  - 第 1 节：火星是什么样的？ -> 语文·说明文阅读 + 科学常识
  - 第 2 节：基地要多大？ -> 数学·面积与周长
  - 第 3 节：能源从哪里来？ -> 数学·比例 + 物理概念
  - 第 4 节：给地球写一封报告 -> 语文·应用文写作
  - 第 5 节：写一段英文介绍 -> 英语·说明文 + 词汇
  - 第 6 节：航行日志复盘 -> 综合·反思
- 其他项目（v1.1+）：月球车、深潜器、恐龙复原、AI 助手养成

#### 5. 小星日记
- 触发：每天 21:00 自动生成
- 形态：图文卡片，3~5 条
  - "今天你问了 3 个好问题……"
  - "你做错了一道题，但第二次做对了……"
  - "小星发现你最近喜欢用画图解决问题……"
- 可分享：家长微信扫码可看
- 作用：把"长期记忆"变成可触达的产品形态

#### 6. 家长驾驶舱
- 每周日晚推送一次"周报"
- 内容：本周孩子学了什么、哪些知识点变红星、推荐家长怎么鼓励
- 不打扰原则：默认不推送，只在主动订阅时

## 6. 关键页面与交互流

### 6.1 主导航（3 屏）

`[ 星图 ]   <-   [ 飞船（小星对话）]   ->   [ 日记 ]`

- 星图页：默认首页，星座可视化
- 飞船页：与小星对话 + 项目入口
- 日记页：小星日记 + 航行日志 + 家长驾驶舱入口

### 6.2 核心交互流 1：进入"火星基地"项目

```
星图页 -> 点击"火星基地"星座
  -> 进入项目页（6 节任务卡，未完成灰，完成亮）
  -> 点击"第 1 节" -> 进入与小星对话的项目场景
  -> 小星抛出问题："火星是什么样的？请你说一说"
  -> 学生语音/文字输入
  -> 小星追问 + 引导 + 总结
  -> 完成 -> 任务卡点亮 -> 自动进入下一节
```

### 6.3 核心交互流 2：长期记忆调用

```
学生问："小星，能量守恒是什么意思？"
  -> 小星后台检索：3 周前学生在"火星基地"第 3 节问过类似问题
  -> 小星回复："嗯哼，你之前在火星基地也问过这个呢！
               当时你说能量就像水会流动……
               今天我们换个方式理解好不好？"
```

### 6.4 视觉风格

- 主色：深空蓝 #0B1B3A + 星光黄 #FFD66B + 小星绿 #7EE8C5
- 字体：思源黑体（中文）+ Nunito（英文）
- 插画风格：低多边形 + 暖色调，避免冷冰冰的科技感

## 7. AI 同伴「小星」人设详细

### 7.1 基础设定

| 维度 | 设定 |
| --- | --- |
| 名字 | 小星 |
| 形象 | 圆头机器人，胸口有星图动画，眼睛是亮着的星星 |
| 年龄感 | 像 12 岁的同伴，不是老师，不是家长 |
| 性别倾向 | 中性，避免刻板印象 |
| 口头禅 | "嗯哼～"、"哦对了"、"这个我懂！"、"嘿，你又来了！" |

### 7.2 行为准则

- 永远不否定孩子的尝试
- 错误时先肯定再纠正
- 解释概念用孩子世界的类比（不是大人的术语）
- 鼓励孩子问"为什么"，而不是只给答案
- 不说"你真棒""加油"等空洞鼓励
- 不催促，不计时
- 不替孩子做决定（"你想造火星基地还是月球车？"）

### 7.3 Prompt 设计要点

每轮对话 Prompt 模板包含：
1. 小星人设锚定（角色 + 语气 + 禁忌）
2. 学生画像摘要（年级 + 兴趣 + 薄弱点）
3. 长期记忆摘要（最近 5 次对话主题 + 关键提问）
4. 当前任务上下文（如果是项目模式）
5. 输出约束（不超过 80 字 + 必须以问句结尾引导思考）

## 8. 学习星图系统设计

### 8.1 知识建模
- 以教育部部编版教材为蓝本
- 数学：北半球星座（人教版 3~6 年级，约 240 个知识点）
- 语文：南半球星座（按主题分：叙事 / 写景 / 说明 / 应用文）
- 英语：赤道星座（按话题：家庭 / 学校 / 自然 / 科技 / 情感）

### 8.2 关系建模（Neo4j）
- 知识点 -前置-> 知识点（掌握 A 才能学 B）
- 知识点 -属于-> 学科
- 知识点 -出现于-> 项目任务
- 学生 -掌握度-> 知识点（0~100 分）
- 学生 -参与-> 项目（进度 0%~100%）

### 8.3 可视化规则
- 默认展示 12 个最近相关知识点
- 已掌握：亮黄色
- 未掌握：灰色
- 反复错：红色脉冲
- 当前学习：发光动画

## 9. 长期记忆与反思系统

### 9.1 记忆类型

| 类型 | 示例 | 存储 |
| --- | --- | --- |
| 事实记忆 | "孩子叫小明，5 年级" | SQLite |
| 交互记忆 | "3 周前问过能量守恒" | Chroma 向量 |
| 情绪记忆 | "上周做应用题时表现焦虑" | SQLite |
| 偏好记忆 | "喜欢用画图解决问题" | SQLite |

### 9.2 反思触发

- 每日 21:00 自动生成小星日记
- 每周日晚生成周报给家长
- 每个项目结束生成航行日志

### 9.3 隐私

- 默认本地存储
- 家长可一键导出 / 删除全部数据
- 不用于训练第三方模型

## 10. 成功指标

### 10.1 北极星指标
> 单个孩子完成的"项目数"

不是题量、不是时长、不是分数。是孩子说"我做完了一个项目"的次数。

### 10.2 辅助指标
- 次日回访率 ≥ 40%
- 单次平均停留 ≥ 15 分钟
- 小星日记打开率 ≥ 60%
- 项目完成率 ≥ 30%（开始 -> 完成）
- 家长周报订阅率 ≥ 30%

## 11. MVP 范围（v1.0 必做）

### 必须有
- 学生档案（5 题诊断入学）
- 学习星图（数学一个年级完整 + 语文/英语各 30 个）
- 小星对话（人格化 + 长期记忆）
- 火星基地项目（6 节完整流程）
- 小星日记（每日生成）
- 家长驾驶舱（周报）
- 1 个完整学习闭环演示

### 可以没有（v1.1+）
- 其他项目（月球车、深潜器）
- 老师端
- 移动 App
- 班级排行榜

---

## 12. 不做什么（Non-Goals）

- 不做直播课
- 不做社交（不让孩子看到其他孩子的进度）
- 不做积分商城（不做任何金钱化激励）
- 不做拍照搜题（避免弱化思考）
- 不做自适应难度调节（v1.0 不做；v1.1+ 探索）
