# ai-study 演示脚本（3-5 分钟路演版）

版本：v0.1 · 角色 E 出品 · 配合「演示控制台」使用

## 演示目标

一条线讲完「诊断 → 路径 → 辅导 → 错题 → 报告」完整闭环，让评委看到：
不是套壳聊天，而是真正有 Agent 架构（工具痕迹）和自适应策略（路径变化）。

## 分段脚本

| 时间 | 环节 | 操作 | 讲解词要点 |
| --- | --- | --- | --- |
| 0:00-0:15 | 痛点 | 停留在首页 | 小学生三科薄弱点各不相同，家长不知道从哪里补起，刷题 App 无法真正诊断 |
| 0:15-0:45 | 学生进入 | 演示控制台 → 一键演示第 1 步 | AI 伙伴读取学生画像后个性化问候（连续 7 天，四年级） |
| 0:45-1:45 | 三科诊断 | 第 2-3 步 | 数学、语文、英语各 3 题；提交后展示 9 个知识点掌握度更新与 3 个薄弱点 |
| 1:45-2:30 | 学习路径 | 第 4 步 | 路径地图按薄弱点优先排任务，前置依赖自动检查（分数 ← 除法） |
| 2:30-3:30 | 数学辅导 | 第 5 步，学生答错 | AI 不直接给答案：3 级提示（找已知条件 → 画图 → 公式），展示 strategy=socratic 与工具痕迹 |
| 3:30-4:00 | 错题本 | 第 6 步 | 错题按 SM-2 调度复习，标出下次复习日期与错因标签 |
| 4:00-4:30 | 家长报告 | 第 7 步 | 掌握度雷达图、错因统计、下周 3 条建议 |
| 4:30-5:00 | 技术收尾 | 演示控制台 Agent 痕迹面板 | LangGraph 状态机：diagnose → update_mastery → plan_path → tutor → reflect；模型可切换（spark/deepseek/mock） |

## 演示前 Checklist

- [ ] `应用/web` 本地可启动（npm run dev）
- [ ] 后端未就绪时，确保 `VITE_USE_MOCK=true`（默认）
- [ ] 演示控制台一键流程可跑通（切换两名学生对比路径差异）
- [ ] 屏幕分辨率 ≥ 1280px，避免左右边缘挤压
- [ ] 提前录屏一份 3-5 分钟素材备用（OBS / 系统录屏）

## 常见问题预案

| 突发情况 | 应对 |
| --- | --- |
| 网络断 / API 挂了 | mock 模式兜底，页面不依赖外网 |
| 评委问模型是哪家 | 答：模型网关可配置，演示用 mock/DeepSeek，赛事亮点可接讯飞星火与语音 |
| 评委问为什么是 React | 答：组件生态 + AI 对话 + 后续 PWA/Tauri 封装 |
| 时间不够 | 砍掉错题本细节，保留 诊断→路径→辅导→报告 主干 |
