# ai-study 课堂展示与学生材料包

这是给老师课堂展示、学生课后阅读和角色领取使用的材料包。

## 推荐阅读顺序

1. `00-课堂展示讲义-v0.3.docx`
2. `01-总PRD与协作规则.md`
3. `02-课堂展示讲义.md`
4. `03-技术栈与架构学习指南.md`
5. `04-文档领取与版本升级指南.md`
6. `05-Git协作规范.md`
7. `08-A-E角色分工确认看板.md`
8. `roles/` 中自己负责的角色文档
9. `templates/学生创意方案模板.md`

## 文件说明

- `00-课堂展示讲义-v0.3.docx`：老师可以直接打开并投屏。
- `01-总PRD与协作规则.md`：说明项目目标、架构、分工和总验收。
- `02-课堂展示讲义.md`：课堂讲解的 Markdown 版本。
- `03-技术栈与架构学习指南.md`：帮助学生理解并判断技术选型。
- `04-文档领取与版本升级指南.md`：说明每个人必须读哪些文档，以及课后如何升级版本。
- `05-Git协作规范.md`：说明分支、提交、PR 和验收规则。
- `06-OpenAPI接口契约草案.yaml`：前后端共同遵守的接口合同。
- `07-讯飞星火与语音Key获取.md`：需要模型或语音时参考，星火不是唯一模型选择。
- `08-A-E角色分工确认看板.md`：课堂确认五位同学角色。
- `roles/`：A-E 五份详细执行文档。
- `templates/`：学生创意方案、课后最终方案、日报和 PR 模板。

## 当前版本

当前是 `v0.3 课前讨论版`。老师确认学生创意方案后，会按 `04-文档领取与版本升级指南.md` 的流程升级为 `v0.4 方案整合版` 或 `v1.0 开发基线版`。
