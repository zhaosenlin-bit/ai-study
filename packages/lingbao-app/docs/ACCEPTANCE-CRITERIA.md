# 灵宝 AI 伴学 — 验收标准 v1.0

> 基于 GitHub 上 6 个对标项目研究,合并行业实践形成 5 大类 30+ 条验收基线。
> 对标项目详见 [REFERENCES.md](./REFERENCES.md)。

---

## 1. 教学有效性(Instructional Effectiveness)

> 这是"灵宝"真正有价值的硬指标。

| # | 指标 | 基线 | 测量方式 |
|---|---|---|---|
| IE-1 | **诊断-课程匹配率** | ≥ 85% | 用户诊断出 A 水平,首课必须从 A 难度开始 |
| IE-2 | **课程完成率** | ≥ 70% | 一个 7 天计划内,学生完成的任务数 / 计划任务总数 |
| IE-3 | **30 天知识点保留率** | ≥ 65% | 上一周期答对的题,30 天后随机抽 10 题重测,正确率 |
| IE-4 | **AI 讲解准确率** | ≥ 85% | 抽样 50 条 AI 讲解,人工评审"是否回答了问题且无事实错误" |
| IE-5 | **错题入复习队列率** | 100% | 答错的题必须自动入错题本,30 天内被复现 ≥ 1 次 |
| IE-6 | **重学意愿** | ≥ 40% | 7 日内至少二次打开 App 的用户占比 |
| IE-7 | **每日学习时长达成率** | ≥ 50% | 每日目标 20 分钟,达到的天数占比 |

## 2. 技术质量(Technical Quality)

| # | 指标 | 基线 | 测量方式 |
|---|---|---|---|
| TQ-1 | **App 冷启动** | ≤ 3 秒 | Pixel 7 / iPhone 13 实测,从点击图标到首页可交互 |
| TQ-2 | **首页首屏 TTFB** | ≤ 800 ms (P95) | 列表首页第一字节时间 |
| TQ-3 | **关键 API 响应** | ≤ 2 s (P95) | 诊断/计划/讲解 API |
| TQ-4 | **崩溃率** | ≤ 0.5% | Crashlytics / Sentry,7 日滑动窗口 |
| TQ-5 | **关键服务可用性** | ≥ 99.9% | 后端 30 日滑动窗口(允许维护窗口) |
| TQ-6 | **APK / IPA 体积** | ≤ 100 MB | release 构建,主包不含教材 PDF(按需下载) |
| TQ-7 | **电量消耗** | ≤ 8%/小时 | 持续学习 1 小时,前台播放 |
| TQ-8 | **离线能力** | 100% | 关闭网络后,今日任务仍可完成(诊断/计划生成需联网) |
| TQ-9 | **滚动帧率** | ≥ 50 FPS | 学情报告/长列表,中端机 |
| TQ-10 | **文字渲染清晰度** | 100% | Retina 屏无模糊 |

## 3. 数据安全与儿童隐私(Data Security & Governance)

> 本项目涉及未成年人,合规是硬门槛。

| # | 指标 | 基线 | 测量方式 |
|---|---|---|---|
| DS-1 | **数据本地化** | 100% | 全部学习数据存本地 SQLite,无任何远程备份 |
| DS-2 | **静默数据加密** | AES-256 | 本地数据库 + localStorage 加密 |
| DS-3 | **无第三方追踪** | 100% | 不集成 Analytics、Crash 报告 SDK 可选(可关闭) |
| DS-4 | **无广告** | 100% | App 内无任何广告位/推广位 |
| DS-5 | **家长可见性** | 必需 | 启动可一键进入"家长模式",显示所有孩子档案 |
| DS-6 | **数据导出/删除** | 必需 | 设置页提供"导出学习记录"和"清空所有数据" |
| DS-7 | **COPPA 兼容** | 是 | 不收集 13 岁以下个人信息 |
| DS-8 | **API 通信加密** | TLS 1.3 | 所有后端调用走 HTTPS |
| DS-9 | **家长密码** | 可选 | 设置 4 位 PIN 才能切换孩子档案或清空数据 |

## 4. 负责任的 AI(Responsible AI)

| # | 指标 | 基线 | 测量方式 |
|---|---|---|---|
| RA-1 | **儿童内容过滤** | 100% | 输入/输出均过滤暴力/性/毒品/仇恨/自残类内容 |
| RA-2 | **单次对话上下文** | ≤ 4K tokens | 超出滚动截断,保留最近摘要 |
| RA-3 | **不可诱导性** | 是 | 越狱/钓鱼 prompt 必须被拦截并温柔拒绝 |
| RA-4 | **模型中断兜底** | 100% | API 超时/5xx 自动降级到 mock + 本地缓存 |
| RA-5 | **AI 输出护栏** | 100% | 讲解中不得出现"我不会""我是 AI"破坏沉浸感(可元话语,但有规范) |
| RA-6 | **数据反馈闭环** | 是 | 用户可对讲解/题目"点赞/点踩",反馈入训练集 |
| RA-7 | **偏见检测** | 必需 | 每千条讲解随机抽 5 条做性别/地域/方言偏见评估 |
| RA-8 | **模型版本可追溯** | 是 | 每次讲解标注模型名+版本,可回滚 |

## 6. 验收方式(交付时跑)

1. **自动化脚本**:`tools/verify_release.py` 跑 IE-1/IE-5、TQ-1/TQ-6、RA-1/RA-4、DS-1/DS-8
2. **真实设备**:Pixel 7 + iPhone 13 上跑 TQ 系列 + DS-1
3. **人工评审**:IE-4(50 条 AI 讲解)、RA-7(偏见)、BI-4(NPS 调研)
4. **家长测试**:5 组真实家庭(双职工,小学 + 初中各 2-3 个孩子)试用 2 周,看 IE-2/IE-3/IE-6/BI-1~3
