# 灵宝 AI 伴学 — PRD v1.0

> 移动端 AI 学习伴侣,以"宠物精灵"为主视觉,主动打招呼 → 学情诊断 → 个性化计划 → 跟随学习。
> 独立交付应用 · 2026.08.28

---

## 1. 产品定位

**"灵宝 AI 伴学"** 是一款面向 小学三至六年级 + 初一至初三 学生的移动端 AI 学习伴侣 App(Android + iOS),其核心差异点:

- **一只活泼的大型宠物精灵"灵宝"作为主视觉与情感核心**(占首页 40%+ 高度)
- **三科(语/数/英)自适应学习路径 + 知识图谱诊断**
- **主动情感交互**:进入即打招呼、诊断前鼓励、答对庆祝、答错安慰
- **完全单机本地化**:不登录、无账号、无云同步(可切换多个孩子档案)

## 2. 目标用户与场景

| 角色 | 需求 | 我们的设计 |
|---|---|---|
| 小学 G3-G6 学生 | 课前预习、课后复习、家长无暇陪伴时的练习 | 灵宝主动发起对话,游戏化练习,情绪反馈 |
| 初中 G7-G9 学生 | 升学压力、难点自查、刷题 | AI 出题讲解,基于错题自适应推题 |
| 家长 | 切换孩子档案、不接管 | 启动选孩子,数据本地隔离,简洁管理 |

**核心使用场景**:孩子放学回家打开 App → 灵宝迎接 → 开始今日计划 → 学习一课(20 分钟) → 灵宝总结鼓励 → 关闭 App。

## 3. 范围

### 3.1 学科 & 年级
| 学科 | 版本 | 年级 | 题库(目标) | 知识图谱(目标) |
|---|---|---|---|---|
| 语文 | 统编版(人教) | G3-G6 + G7-G9 | 小学 50+ / 初中 60+ | 小学 30+ / 初中 40+ |
| 数学 | 北师大版 | G3-G6 + G7-G9 | 小学 60+ / 初中 60+ | 小学 32(已有)+ 初中 25+ |
| 英语 | 人教版(PEP) | G3-G6 + G7-G9 | 小学 80(已有)/ 初中 60+ | 小学 52(已有)+ 初中 30+ |

### 3.2 功能模块
1. **宠物精灵"灵宝"**(核心差异化)
   - 32 种表情(emotion-ball 引擎) × 自设计"灵宝"角色形象
   - 主动打招呼(进入即触发)
   - 学习状态联动:答对→开心(13)/庆祝(38)/鼓掌;答错→困惑(36)/鼓励(15);思考→检索中(30)/思考环带
2. **学情诊断**(首次进入)
   - 三科各抽 5-10 题(根据年级自适应难度)
   - AI 评估知识掌握水平,标注强弱项
   - 生成"诊断报告卡"
3. **个性化学习计划**
   - 基于诊断结果 + 知识图谱前置依赖,生成 7-14 天计划
   - 每日 3 个任务卡:1 主课讲解 + 2 练习巩固
   - 灵宝在每张卡前"预习+预告"
4. **学习闭环**
   - 讲解页:AI 讲解知识点(文字+语音+插图)
   - 练习页:答题、即时反馈、错题自动入复习队列
   - 总结页:每日复盘,灵宝奖励动画
5. **多孩子切换**
   - 启动可选择孩子档案(本地存储)
   - 每个孩子独立数据、计划、进度
6. **可选语音交互**
   - Kokoro TTS(`zf_xiaoxiao` 童声中文)为灵宝配音
   - 语音输入(可选)
7. **家长面板**(简化版)
   - 查看每个孩子的进度、错题、最近 7 天学习时长

### 3.3 不做(MVP 外)
- 云端账号/同步(单机本地)
- 社交/排行榜
- 充值/会员
- 直播/视频课

## 4. 技术栈

```
移动端:  Capacitor 6 + Vue 3 + Vite + TypeScript
         + Pinia(状态) + Vue Router + Day.js + idb-keyval(本地存储)
         + Emotion-Ball 引擎(原生 JS,作 Vue 组件封装)

后端:    FastAPI + LangGraph + SQLAlchemy(复用 ai-study-repo)
         + 模型网关(minimax/deepseek/qwen/spark 自动回退 mock)
         + Kokoro TTS(开源,本地推理)
         + ASR:Minimax/讯飞(可选,默认关闭)

数据:    PostgreSQL(用户/计划/进度)
         + JSON 知识图谱(G7-G9 待补)
         + PDF 教材(C:\my\_know\textbooks\g3_pdfs\)

图像:    JoJoCode Image2 API(灵宝角色变体、讲解插图)

部署:    后端 Docker Compose
         移动端 Capacitor 打包 iOS + Android
```

## 5. 启动流(用户旅程)

```
Splash (灵宝动画 + Logo)
  ↓ 灵宝主动唤醒(02 wake-up → 12 happy,说:"嗨~我是灵宝!")
选孩子 (首次:创建档案;已有:选择)
  ↓
诊断 (每科 5-10 题,灵宝鼓励"答对就夸你")
  ↓
诊断报告 (灵宝说"我了解了,你是 X 水平的宝宝")
  ↓
AI 生成计划 (3-7 天,每日 3 任务)
  ↓
首页 (今日任务卡 + 灵宝待机,眨眼/呼吸)
  ↓
学习闭环 (讲解 → 练习 → 总结)
  ↓
晚安 (灵宝挥手,提醒下次)
```

## 6. UI 设计原则

- **活泼高级透明**:玻璃拟态 + 深空渐变 + 漂浮光斑
- **字体**:圆润无衬线 + 大字号 + 充足留白
- **主色**:透明玻璃 + 高饱和点缀(珊瑚橙、电光紫、薄荷绿)
- **灵宝**:占主屏 40%+ 高度,持续轻量动效(呼吸/眨眼/转头)
- **过渡**:页面间用灵宝表情切换做转场

## 7. 数据隔离

- 每个孩子档案 = 一个 `child_id`
- 学习数据(诊断、计划、进度)按 `child_id` 索引
- 本地 SQLite(WatermelonDB 或 idb-keyval)
- 后端为可选缓存层,可离线工作

## 8. 集成与复用

## 9. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 教材版本未对齐 | 错题偏题 | 严格按"人教/北师大/PEP"标签入库 |
| AI 内容不当 | 儿童安全 | 内容过滤 + 提示词护栏 + 父母确认 |
| 单机数据丢失 | 用户体验 | 引导家长定期导出/备份 |
| 模型中断 | 学习中断 | 本地缓存 + Mock 回退 |
| TTS 引擎体积 | APK 变大 | 服务端 TTS 优先,客户端按需下载 |
